Lenxia 網站 — 正式版原始碼
================================

這是可以直接放進 notes repo 裡、部署到 GitHub Pages 的完整靜態網站。

【資料夾結構】
index.html                主頁面
assets/css/style.css      全站共用樣式表（改顏色/字體只要改這一個檔案）
assets/images/            圖片存放處，README.txt 列出所有需要放進來的檔名
daymoon/index.html        晝行之夜
nightmare/                惡夢之街（index.html 是目錄，其餘是各章節正文）
ticktock/                 Tick Tock（index.html、sirius.html、npc.html，
                           memory/ 底下是蕾妮／隼里／眠鳥正文）
duonan/                   讀喃隱藏頁面（gate.html 是防雷頁，其餘是列表與正文；
                           這個資料夾沒有被任何導覽選單連結，只能透過首頁
                           「記住」兩字的隱藏連結進入）

【下一步】
1. 打開 assets/images/README.txt，把妳下載好的圖片改名放進 assets/images/
2. 把整個 site 資料夾內容複製到 notes repo 底下的 lenxia 資料夾
3. git add . / git commit / git push
